🚀 QUICK START (3 Terminals)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Terminal 1 - Start MongoDB:
───────────────────────────────────────────────────────────────────
brew services start mongodb-community@7.0

# Verify it's running:
brew services list | grep mongodb


Terminal 2 - Start Backend Server:
───────────────────────────────────────────────────────────────────
cd ~/campus-finder-backend
npm start

# Expected output:
# ✅ Server running on port 5000
# ✅ Connected to MongoDB
# ✅ Socket.IO initialized


Terminal 3 - Start Frontend:
───────────────────────────────────────────────────────────────────
cd ~/findme
npm run dev

# Expected output:
# ➜ Local:   http://localhost:5173/


📱 ACCESS YOUR APP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Frontend:  http://localhost:5173
Backend:   http://localhost:5000
MongoDB:   mongodb://localhost:27017


🛑 STOP SERVICES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Stop MongoDB:
brew services stop mongodb-community@7.0

Stop Backend/Frontend:
Press Ctrl+C in their respective terminals


🔧 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Port already in use:
lsof -ti:5000 | xargs kill -9    # Kill backend port
lsof -ti:5173 | xargs kill -9    # Kill frontend port

MongoDB not connecting:
brew services restart mongodb-community@7.0

Backend can't find modules:
cd ~/campus-finder-backend && npm install

Frontend can't find modules:
cd ~/findme && npm install
