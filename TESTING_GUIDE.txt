$ npm start

✅ Socket.IO initialized

Terminal 3 - Frontend:
$ cd ~/findme
$ npm install
$ npm run dev

Expected output:

Problem: MongoDB won't start
────────────────────────────────────────────────────────────────
Solution:
$ brew services restart mongodb-community@7.0
$ ps aux | grep mongod  # Check if running

Problem: Backend "Cannot connect to MongoDB"
────────────────────────────────────────────────────────────────
Solution:
1. Check MongoDB is running
2. Verify MONGO_URI in .env
3. Check firewall settings

Problem: Frontend can't connect to backend
────────────────────────────────────────────────────────────────
Solution:
1. Check backend is running on port 5000
2. Verify VITE_API_BASE_URL in frontend .env
3. Check browser console for CORS errors
4. Backend should have CORS enabled for localhost:5173

Problem: Socket.IO not connecting
────────────────────────────────────────────────────────────────
Solution:
1. Check browser console for connection errors
2. Verify backend Socket.IO is initialized
3. Check firewall/antivirus blocking WebSocket

Problem: Image upload fails
────────────────────────────────────────────────────────────────
Solution:
1. Verify Cloudinary credentials in backend .env
2. Check file size (should be < 5MB)
3. Check browser console for errors

Problem: Email not sending (forgot password)
────────────────────────────────────────────────────────────────
Solution:
1. Verify EMAIL_USER and EMAIL_PASS in .env
2. Use Gmail App Password (not regular password)
3. Enable "Less secure app access" (if using old Gmail)
4. Check backend terminal for email errors

Problem: Login fails
────────────────────────────────────────────────────────────────
Solution:
1. Check backend terminal for errors
2. Verify user exists in MongoDB
3. Check password is correct
4. Clear browser localStorage and try again
