STEP 1: Configure Backend Environment
──────────────────────────────────────────────────────
Edit ~/campus-finder-backend/.env and update:

1. MongoDB URI (already configured for local)
   MONGO_URI=mongodb://localhost:27017/campus-finder

2. JWT Secret (CHANGE THIS!)
   JWT_SECRET=your-super-secret-jwt-key-change-this-in-production-12345

3. Email Configuration (Gmail):
   - Go to: https://myaccount.google.com/apppasswords
   - Generate app password for "Mail"
   - Update:
     EMAIL_USER=your-gmail@gmail.com
     EMAIL_PASS=your-16-character-app-password

4. Cloudinary Configuration:
   - Sign up at: https://cloudinary.com
   - Get credentials from dashboard
   - Update:
     CLOUDINARY_CLOUD_NAME=your-cloud-name
     CLOUDINARY_API_KEY=your-api-key
     CLOUDINARY_API_SECRET=your-api-secret

STEP 2: Start MongoDB
──────────────────────────────────────────────────────
brew services start mongodb-community@7.0

Verify: mongosh --eval "db.version()"

STEP 3: Start Backend Server
──────────────────────────────────────────────────────
cd ~/campus-finder-backend
npm install
npm start

Expected output:
✅ Server running on port 5000
✅ Connected to MongoDB
✅ Socket.IO initialized

STEP 4: Start Frontend Development Server
──────────────────────────────────────────────────────
cd ~/findme
npm install
npm run dev

Expected output:
➜ Local: http://localhost:5173/

Fix: Verify Cloudinary credentials
     Check browser console for errors

Fix: Check CORS configuration in backend
